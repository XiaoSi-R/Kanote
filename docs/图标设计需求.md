# Kanote 图标设计需求

## 基本信息

- **应用名称**：Kanote
- **应用定位**：本地桌面待办 + 笔记工具
- **平台**：Windows 桌面应用
- **品牌主色**：橙色 `#f39c12` + 绿色 `#27ae60` / `#2ecc71`

## 核心功能

| 功能 | 说明 |
|------|------|
| 📋 看板 | 两列卡片（待开始 / 今天完成），拖拽排序，置顶 |
| 📝 笔记 | 分类标签，全文搜索，全屏编辑 |
| 🪟 小窗模式 | 双击标题栏缩成悬浮小窗（440×680），双击恢复 |
| 🌓 暗色模式 | 浅色/深色主题一键切换 |
| 🔍 搜索高亮 | 看板和笔记均支持关键词黄底高亮 |
| 📤 导入导出 | Excel 导入导出，JSON 导出 |
| 🔔 系统托盘 | 最小化到系统托盘，右键菜单恢复/退出 |

## 图标规格

```
ICO 格式，需包含以下 8 个尺寸：
16 × 16  px   （列表/小图标视图）
24 × 24  px   （开始菜单小）
32 × 32  px   （任务栏/托盘）
48 × 48  px   （中图标视图）
64 × 64  px   （大图标）
96 × 96  px   （大图标）
128 × 128 px  （超大图标）
256 × 256 px  （超大图标/资源管理器预览）
```

- **格式**：.ico（Windows 图标格式）
- **背景**：纯白底圆角
- **各尺寸独立绘制**，保证每个尺寸清晰无缩放模糊
- **颜色模式**：32-bit（RGBA，含透明通道）

## 设计方向

**方案 A — K 字母图标（当前）**：
- 橙色竖条（左）+ 绿色上下臂（右），构成 K 字形
- 简洁，品牌识别度高

**方案 B — 双栏看板图标**：
- 两个并排矩形代表看板的两列
- 一列橙色（待开始）、一列绿色（已完成）
- 更能直观表达应用功能

**方案 C — 自由发挥**：
- 设计师根据 Kanote = Kanban + Note 自由创意

## 技术要求

每个尺寸的图标需要**在该尺寸下逐像素绘制**，不要依赖单一大图缩放到小尺寸，否则小图标会模糊。
